# Prototype

A throwaway sketch to settle a UI or behavior question by looking at it, not by asking.

Use when the fork is empirical: layout, copy, a command's output, a flow shape. Do not use when the answer is already in `AGENTS.md`.

1. State the question in one sentence and what you will observe.
2. Smallest sketch in this repo's stack. No new schema. No new util package. No production flow.
3. Blast radius: what you will delete if the sketch loses.
4. Show the thing (screen, command output, or whatever this repo runs). Do not describe it instead.
5. `/no-comments` and `/deslop` if any of it stays. If it is throwaway, delete it or leave it on `feature/*` marked as sketch.
6. Stop. The human picks. Then either throw away or re-match `feature`.
